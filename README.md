## 👋 Sobre mí

Empecé a programar con un juego en Python y desde entonces no he parado de aprender por mi cuenta. Administro y desarrollo plataformas académicas reales para mi colegio, y disfruto tanto construir software como enseñar lo que aprendo en el camino.

Mi meta es doble: **ingeniero de sistemas y docente**. A largo plazo quiero liderar una institución educativa pública y usar tecnología para transformar cómo se enseña y se gestiona la educación.

- 🔭 Actualmente desarrollo y administro un **sistema escolar integral (PWA)** para mi curso, XI-10.
- 🌱 Aprendiendo `TypeScript`, `React`, `Java` y `Spring Boot`.
- 🎯 Explorando la ruta hacia la docencia en tecnología: Técnico en Programación de Software (SENA) → Normalista Superior / licenciatura → Ingeniería de Sistemas.
- 🤝 Abierto a colaborar en proyectos EdTech, sobre todo herramientas para instituciones públicas.
- ⚡ Dato curioso: mis primeros pasos en programación fueron construyendo un juego en Python.

## 🚀 Proyectos destacados

### 🗓️ Horario INEM XI-10 — Sistema Escolar Integral (PWA)
Plataforma web progresiva construida sobre **Firebase (Firestore + Authentication)** que administro activamente para mi curso. Nació como un simple horario de clases y creció hasta convertirse en un sistema con múltiples roles (administrador, profesor, monitor, estudiante).

**Funciones clave:**
- Horario de clases y control de asistencia
- Tarjetas de compromisos y cartelera comunitaria con encuestas anónimas
- Calculadoras de notas, temporizador Pomodoro y modo de presentación para TV
- Notificaciones push vía Cloud Functions
- Identidad visual propia (paleta dorado/negro/crema, tipografía EB Garamond)

`Firebase` `Firestore` `JavaScript` `PWA` `Cloud Functions`
